# Лабораторная работа № 4. Самостоятельное применение шаблонов проектирования

## Цели и задачи

- Самостоятельно изучить и практически применить шаблоны, вынесенные на углублённое самостоятельное изучение.
- Научиться распознавать проектную проблему до выбора шаблона.
- Научиться сравнивать альтернативные решения и оценивать последствия применения шаблонов.
- Закрепить навыки проектирования, тестирования и документирования решения.

## Допустимые шаблоны

Для выполнения работы необходимо выбрать **два различных шаблона** из списка:

- **Prototype (Прототип)**;
- **Bridge (Мост)**;
- **Flyweight (Легковес)**;
- **Memento (Снимок)**;
- **Visitor (Посетитель)**.

Именно эти два шаблона считаются основными оцениваемыми шаблонами лабораторной работы.

Шаблоны из предыдущих лабораторных можно использовать дополнительно, если они действительно необходимы, но они не заменяют два шаблона из приведённого списка.

## Исходный проект

В качестве предметной области используется простой редактор векторного рисунка.

Проект уже умеет:

- хранить документ с фигурами;
- работать с окружностями, прямоугольниками и текстовыми метками;
- перемещать фигуры;
- хранить стиль каждой фигуры;
- выводить рисунок в текстовом виде;
- экспортировать документ в словарь для дальнейшей сериализации.

Часть исходного кода намеренно содержит признаки будущих проектных проблем: условные конструкции по типу фигуры, дублирование данных стиля, отсутствие истории изменений и механизма копирования.

Это **не означает**, что необходимо «исправить всё». Сначала выберите две проектные проблемы, затем примените два соответствующих шаблона.

Проверка исходного проекта:

```bash
python -m pytest
python app.py
```

## Возможные направления применения шаблонов

### Prototype

Подходит, если вы решаете задачу создания копий сложных фигур, пользовательских шаблонов или групп объектов.

### Bridge

Подходит, если требуется независимо развивать абстракцию фигур/документа и способы визуализации.

### Flyweight

Подходит, если большое число фигур имеет одинаковые стили и требуется разделить внутреннее и внешнее состояние.

### Memento

Подходит для сохранения состояния документа, undo/redo и восстановления состояния без раскрытия внутреннего устройства объекта.

### Visitor

Подходит, если требуется добавлять операции над стабильным набором типов фигур: экспорт, статистику, анализ или диагностику.

## Задание и порядок выполнения

1. Изучите исходную архитектуру.
2. Выберите две конкретные проектные проблемы.
3. Для каждой проблемы выберите один шаблон из разрешённого списка.
4. В README до реализации кратко зафиксируйте проблему, выбранный шаблон, минимум одну альтернативу и причину отказа от альтернативы.
5. Реализуйте два выбранных шаблона.
6. Покажите их совместное применение в `app.py` либо в отдельном демонстрационном сценарии.
7. Напишите автоматические тесты.
8. Подготовьте структурную диаграмму итогового решения.
9. В разделе **«Анализ решения»** опишите роли участников, достоинства, ограничения, появившуюся сложность и оправданность применения шаблона.

## Запрещённый подход

Не считается выполнением работы:

- создать классы с названиями `Prototype`, `Visitor`, `Memento` и т. п. без соответствующей структуры взаимодействия;
- применить шаблон там, где он не решает сформулированную проблему;
- полностью переписать исходный проект без объяснения причин;
- использовать два шаблона только потому, что они проще всего реализуются.
